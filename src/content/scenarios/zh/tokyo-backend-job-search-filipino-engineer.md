你可能担心：N4 会不会让所有门都关上？六年后端经验够不够？第一次发薪前，搬家会不会先花光存款？

我的判断是，这条路值得走。Go 和 Python 是不错的起点，重点找已经用英语协作、愿意从海外招工程师的团队。眼下最大的未知，不是日文，而是你的学历或资格能不能满足工作在留资格要求。

这里以住在菲律宾、有六年后端经验、JLPT N4 的菲律宾籍工程师为例，目标是在 **2027年10月1日**前到东京入职。使用中文的工程师也能参考，但申请人仍是菲律宾籍，出境要求不会随语言改变。这是友好的规划信息，不是移民或法律意见；请让雇主的合资格顾问核对你的实际文件。

## 先记住这几件事

- **税前年薪目标：¥8–11m**——这是建议的谈薪区间，不是保证拿到的邀约。如果团队、工作量和搬迁支持确实好，可以考虑 ¥7m。六年经验不自动等于资深。这里 m 表示百万日元。
- **出发前准备约 ¥1.5m 可动用资金**——按一位成人估算，包含安置费用和单独保留的三个月缓冲。只有支持已书面确认，才相应减少。
- **这周先确认学历和资格门槛。**只靠六年工作经验，低于通常的十年经验替代要求。别面试几个月后才发现这一步还没解决。
- **现在开始找，手续齐了再搬。**“十月前”可以是春夏提前入职。如果只能十月开始，把主要的 16 周求职期移到2027年3月1日至2027年6月20日。

**先看 Jamm 和 Money Forward。**Python 专项年限满足时再加 HENNGE。能展示分布式系统能力、也愿意换生产栈，再选 PayPay 或 Securities。更宽泛的备选，只选额外工作也真正合适的。不把要求商务日语、仅限在日居民或硬性七年、九年经验的职位凑进来，假装 N4 和六年就够。

## 先确认普通工程师路线，再看高度人才积分

### 技术、人文知识、国际业务

对符合要求的后端工程岗位，这是通常的工作在留资格起点。你需要与日本机构有真实合同，技术职责符合资格范围，报酬不低于从事可比工作的日本员工。请看 [ISA 申请页](https://www.moj.go.jp/isa/applications/status/gijinkoku.html)和[入境标准第 1 页](https://www.moj.go.jp/isa/content/001366995.pdf)。

- **有相关大学学历或同等教育背景？**收好毕业证和成绩单。目前没有提供学历与专业，资格仍未确认。
- **没有合资格学历？**替代路线通常要求十年相关经验，部分符合条件的相关学习时间可以计入。单靠六年工作不够，别把所有上学年限都算入，也别重复计算重叠时间。
- **合资格日本专门学校资格是另一个分支。**不是任何海外短期文凭都被认可，请雇主顾问核对具体学校、课程和文件。
- **IT 有指定考试例外。**[官方指定考试公告第 3 项](https://www.moj.go.jp/isa/policies/bill/nyukan_hourei_h09.html)列有菲律宾 PhilNITS FE 和 AP。符合要求的合格证明，可替代相关 IT 工作的学历或十年经验分支；普通云证书不自动合格。考试是否开考、个人是否通过、与职责是否相符，仍须核对。

**N4 不是后端工作一律过不了签证的理由。**技术标准没有统一 N2 门槛。ISA 页面的 **2026年4月15日**调整，是要求主要做语言型人际服务工作的第 3/4 类个案提供 B2 同等语言证明，不是全体软件工程师都必须 N2。ISA 仍可按个案要求补证，雇主的招聘要求则是另一回事。

### 从菲律宾出发，顺序很重要

- 先拿到符合要求的书面邀约，确认谁负责担保和菲律宾一侧手续。
- 雇主在日本的授权代表准备 **在留资格认定证明书（COE）**申请。你提供护照、学历和工作证明及其他所需文件；雇主材料按类别不同。ISA [公布的 COE 标准处理时间](https://www.moj.go.jp/isa/applications/procedures/16-1.html)为 **1–3 个月**，不是期限或保证。
- 拿到 COE 后，通过有管辖权的日本使领馆当时适用的工作签证渠道递交。[日本外务省](https://www.mofa.go.jp/j_info/visit/visa/long/visa1.html)说明，COE 支持申请，但不保证获签。递交时再确认菲律宾当地渠道。
- 完成适用的菲律宾海外就业出境手续，再旅行并接受入境审查。录用通知、COE 或观光入境，都不是开始工作的许可。

**菲律宾申请人容易漏掉的两项。**按 [ISA 入境前结核筛查规则](https://www.moj.go.jp/isa/10_00219.html)，住在菲律宾、申请新的中长期入境的菲律宾国民，一般须在指定诊所取得结核清除证明。**2025年6月23日**起强制提交，通常从检查日起有效 **180 天**。配合 COE 时间办，不要提前一年。住在目标国家以外，以及特定项目等情况，会影响适用范围。[MWO-Tokyo 直接雇用禁令豁免清单](https://mwo-tokyo.dmw.gov.ph/index.php/2025/08/04/exemption-on-the-ban-on-direct-hiring/)发表于2025年8月4日，要求雇主配合，并另做合同核验。公布的 **10–15 个工作日是核验周期**，不是整个出境手续时间。请 DMW/MWO 确认直接雇用豁免还是持牌中介路线、现行体检与培训及保险步骤，以及准确的 OEC 或出境许可要求。2027年全流程仍须 **另行核实**，有日本签证不等于菲律宾手续也完成了。

所引 MWO 清单说明，合同核验本身不收费，但不代表体检、保险或整个派遣过程免费。请雇主确认适用路线和每项成本；下方机票及文件预留，不一定涵盖你实际的菲律宾派遣费用。首次海外派遣，不要默认适用返岗工人的豁免。

### 高度人才 1(b)：可以评估，不是自动获得

高级专业技术活动的积分路线要求 **70 分**、符合底层活动及资格条件，并有至少 **¥3m 年报酬**。这个最低值不是建议工资。请看 [ISA 积分表第 1 页](https://www.moj.go.jp/isa/content/001398882.pdf)、[评估页](https://www.moj.go.jp/isa/applications/resources/newimmiact_3_evaluate_index.html)和[官方常见问题](https://www.moj.go.jp/isa/applications/resources/newimmiact_3_qa.html)。所链接积分表未标日期，2026年11月6日查阅。

| 因素 | 这个例子可怎样粗算 |
| --- | --- |
| 学历，未知 | 学士或同等 10；硕士 20；博士 30。按适用的最高类别，不是三项相加。 |
| 相关经验 | 六年 = 10；完成七年 = 15；十年 = 20。不是到了 2027 就自动升级。 |
| 年龄，未知 | 29 岁及以下：15；30–34：10；35–39：5；40+：0。按评估时年龄。 |
| 日语 | N4 = 0；N2 = 10；N1 = 15。不累加；取得日本高等教育加分时，N2 也有不适用的限制。 |
| 邀约报酬 | 各年龄段 ¥8m = 30；¥9m = 35；¥10m+ = 40。¥7m 在未满 40 岁时 = 25，40+ 时薪资积分为 0。更低门槛按年龄变化。用合资格接收机构的报酬，不算假设股权或不确定加班。 |

**只是算例，不是你的已确认分数：**28 岁 + 学士 + 六年 + ¥8m + N4 = 15 + 10 + 10 + 30 + 0 = **65**。完成七年后变成 **70**。32 岁、同样学士、六年、¥8m 和 N4 是 **60**；有证明的 N2 可升至 **70**。42 岁 + 学士 + 七年 + ¥10m + N4 是 **65**。

这里不假定雇主、大学、科研或考试额外加分。年龄、学历和薪资未知，无法确定你的实际积分。符合条件时，在 HSP COE 流程提交自评表及佐证，不是自动升级。达不到高度人才积分，不代表一定拿不到普通工程师在留资格；别只为追积分推迟一份合适的工作。

## 第一次租房，往往最花钱

这份预算按 **一位成人、无家属、无车**，租普通单间或 1K、接受通勤，不是市中心豪宅。所有金额都是 **2026年11月日元水平的估算**，不是2027年10月报价。接受邀约前，重新询房租和机票。
