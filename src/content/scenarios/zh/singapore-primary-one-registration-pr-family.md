你希望儿子顺利入学，也不想为了并不存在的录取优势多交房租。对这个新加坡永久居民（PR）家庭来说，**通常应走 Phase 2C，而不是 Phase 3**。先选一家人能真实居住的房子，再看学校最后录取到哪个组别，不能只看总空缺。

这份计划面向父母在2025年成为 PR、没有已知合资格学校关系、考虑美世界及新加坡西部更大范围的家庭。目标是2027年报名、2028年入学。**留存的教育部（MOE）资料尚未公布2027年各阶段的确切日期。** 页面显示的是上一届日程，不要拿它安排旅行或设置报名提醒。

先核对儿子的准确生日。预计对应出生范围为2021年1月2日–2022年1月1日，含首尾两天。这是根据 [MOE 概览](https://www.moe.gov.sg/primary/p1-registration)的年度规则推算，并非新公布的日程。如果生日是2021年1月1日，就属于更早一届，需要另作安排。下文资料保存于2026年11月6日–2026年11月7日，本指南没有重新查询来源。

## 按真实资格选择报名阶段

成为 PR，不会自动产生校友、义工或社群关系。可以核对已有的真实关系，但不要把计划押在临时取得资格上。

| 阶段 | 资格 | 对这个家庭的意义 |
| --- | --- | --- |
| 1 | 兄弟姐妹目前在该校就读。 | 未提供这项关系。所有合资格申请者都会获得学位。 |
| 2A | 父母或兄弟姐妹是校友；父母是学校咨询或管理委员会成员，或学校职员；或孩子就读该校内的 MOE 幼儿园。 | 父母都不是校友，只排除了校友这条路，并非排除所有可能关系。未提供其他合资格关系。 |
| 2B | 符合条件的家长义工、与学校直接关联的教会或会馆认可的成员，或获认可的活跃基层领袖。 | 目前没有这项资格。做义工也不保证录取。 |
| 2C | 尚未在小学注册的 SC 或 PR 孩子。 | 应作为主要报名路线。 |
| 2C Supplementary | 主要阶段结束后仍未注册的 SC 或 PR 孩子。 | 申请剩余学位。若仍不成功，MOE 会分配到有空缺的学校，不保证是心仪学校，也不保证在2 km内。 |
| 3 | 既不是 SC，也不是 PR 的国际学生，另有流程。 | 不适用于儿子，也不是 PR 的后备轮次。 |

SC 指新加坡公民。请按 [MOE 阶段规则](https://www.moe.gov.sg/primary/p1-registration/registration-phases-key-dates)和[报名说明](https://www.moe.gov.sg/primary/p1-registration/how-to-register)操作。同一阶段只能报一所学校；MOE 以该阶段最后提交的申请为准。提早提交不会提高抽签优先级。通常在线报名。普通门户申请者一般无需提交文件，使用在线表格路径时除外；学校仍可能要求补充资料或说明。先备好身份及亲属关系记录，再按当届要求办理。

本届普通家长义工路线要求最迟于2026年7月1日加入，并于2027年6月30日前完成至少40小时服务。现在才开始，通常已经太迟。这只是服务时数下限，不含交通和排班投入。即使 PR 家长满足义工资格，在适用公民优先的情况下仍排在 SC 申请者之后。不要以为捐款或临时声称的社群关系可以买到优先权。

## 住得近，不能越过公民优先

普通学校超额申请时，顺序是：

**SC ≤1 km → SC >1–2 km → SC >2 km → PR ≤1 km → PR >1–2 km → PR >2 km。**

最远距离组的公民，也排在最近距离组的 PR 前面。学位不足时，会在最先超出剩余学位的组别内抽签，之后的组别无法录取。MOE 统一进行电脑抽签，同一须抽签组别内机会均等。从 Phase 2A 到 Phase 2C Supplementary 都可能抽签。可看[距离优先规则](https://www.moe.gov.sg/primary/p1-registration/distance)和[抽签说明](https://www.moe.gov.sg/primary/p1-registration/understand-balloting)。“不用抽签”不一定代表所有申请者都获录取。

### 下一届，部分学校的距离规则会变

MOE 于[2026年9月10日公布的调整](https://www.moe.gov.sg/news/press-releases/20260910-enhancing-the-primary-one-registration-framework-for-greater-access-and-inclusivity)适用于2027年报名、2028年入学。多数学校的 Phase 2C 保留学位从40个增至60个，招生规模较小的学校除外。Phase 2B 仍保留20个。这些学位来自原有招生名额，不是额外为 PR 保留的学位。

[附件 A](https://www.moe.gov.sg/media/newsroom/news/press/2026/b0d58e7a-5220-49b9-bc9c-a7f783a4f510.pdf)列出的12所学校，会把 Phase 2C 学位平均分为 ≤2 km 和 >2 km 两条轨道。每条轨道内部没有1 km优先。两条轨道的 SC 申请者都会先于 PR 获考虑。某轨道有剩余学位时，先给另一轨道的 SC；之后若仍有名额，才平均分给 PR 的两条轨道。奇数多出的一个名额归较近轨道。

因此，从1.8 km搬到0.8 km，并不能提高同一轨道内的优先级。下表的 Pei Hwa、Methodist Girls' 和 Raffles Girls' 在公布名单上。后两所是女校，仍不适合儿子申请。其他阶段及学校继续按各自适用规则办理。

此外，[指定学校会限制 PR 招生](https://www.moe.gov.sg/primary/p1-registration/cap-on-pr-intake)，主要及补充轮次的上限约为计划招生的25–30%，并计入之前阶段已录取的 PR。这不是所有学校统一适用的配额。**2027年限额学校名单及各阶段上限仍未确认。** 总名额有剩余，不等于 PR 还有名额。

## 让住址安排真正适合一家人

报名使用家长 NRIC 上的正式居住地址，孩子必须实际住在那里。租房并非自动不合资格，但单有租约不等于真实居住。请在报名当年用[官方 OneMap 学校距离服务](https://www.onemap.gov.sg/school)核对实际住家，不要用步行距离、中介地图或以地铁站为圆心的范围代替。

如果凭距离优先获录取，普通住址规则要求**从报名活动开始起至少居住30个月**，报名家长的 NRIC 地址也须保持在那里。不是从你提交当天算起，通常也不是从入学日算起。正式开始日期未定，就不能算出官方届满日期。租约、实际入住证明和官方记录应一致。留存账单是稳妥准备，不是 MOE 对所有家庭统一规定的文件清单。

- **报名前搬家：**先真正入住、更新官方地址，再核对距离。不要使用尚未入住的普通未来租房。符合条件的新房或转售房购买另有文件路径，不能当作未来租房的豁免。
- **报名后搬家：**及时披露地址变化。MOE 允许搬到同一家校距离类别内的新住址，继续履行居住要求。若未完成要求就搬到原类别之外，可能被 MOE 转到指定学校，家长不能选择学校。新双轨制如何实施，需要单独核对，不能直接套用旧距离组别。
- **租期不够：**先争取续租。无法续租并不构成豁免。之后搬家，也不保证能转到更近的学校。如果当初并非凭距离优先录取，应核对实际录取条件，不要假定同一条件完全照搬。

家庭原则上应在孩子小学期间居住于该址；最低期限并不是建议到期立刻搬走。虚假地址可能被调查并转交警方。签租约前，请读 [MOE 住址规则](https://www.moe.gov.sg/primary/p1-registration/home-address)及[搬家与租房问答](https://www.moe.gov.sg/faq?categoryid=E3E39C0FD0F04504A444B1F600CC8430)。

## 用已知基准做预算，不把它当未来收费承诺

对政府及政府资助小学，[已公布收费表](https://www.moe.gov.sg/news/press-releases/20231018-revised-school-fees-for-non-citizens-in-government-and-government-aided-schools-for-2024-to-2026)支持以下2026年月费比较。**这并不确认2028年费用。**

| 身份 | 学费 | 杂费 | 每月合计 |
| --- | --- | --- | --- |
| SC | S$0 | S$13 | S$13 |
| PR | S$330 | S$13 | S$343 |

PR 每月学费在2024年为 S$280、2025年为 S$305、2026年为 S$330，每年增加 S$25。不要自动照这个规律往后加：2027/2028年新收费表尚未确认。按上述基准缴12个月，PR 孩子合计 S$4,116，SC 孩子为 S$156，相差 S$3,960。这只是算术示例，不是未来全年账单。餐食、校服、书本、交通和学生托管另计。

### 把报名承诺与国民服役义务分开看

一般报名承诺在门户或在线表格中声明，特殊情况会收到需电子签署的 Letter of Undertaking。登录后实际声明的完整措辞未被查看。公开资料未能确认额外针对 PR 的国民服役或学费承诺书；这不证明一定没有。请在同意前阅读实际声明。

另外，[CMPB 指引](https://www.cmpb.gov.sg/before-ns/overseas-pre-enlistees)明确把父母担保取得 PR 的男孩纳入国民服役义务：16.5岁登记，18岁后在最早可安排时入伍。这里没有提供儿子的担保途径，请核对其 PR 批准条件。义务来自身份，不是由小学录取产生；签署知悉声明不会增加录取机会，也不构成豁免。

## 接下来这样做

- **现在：**核对生日、真实学校关系及 PR 批准条件。为房租、学校收费、通勤和托管设定可持续预算。
- **搬家前：**核对实际住址、校址、限额名单及适用轨道。选择一家人能在要求期限内真实居住的房子。
- **日程公布后：**记下主要及补充轮次的准确开放、截止和结果时间，不照搬上一届日历。
- **报名期间：**看实际空缺，以及录取截止到了哪一公民身份组别。只报一所你能接受的学校，同时准备较远通勤选项。
- **申请不成功：**走补充轮次，不是国际学生阶段。若仍不成功，按 MOE 有空缺学校的分配办理。私立和国际学校是另一套申请及费用决定。
- **录取之后：**按迎新及托管指示办理，核对入学当年的费用，并遵守录取所附居住条件。

家庭指南（原始辅助文件未公开；请依据本文内容操作）和[来源笔记](#来源与查阅日期)保留了较完整的说明与计算。没有配套工作簿。仍待核对的包括确切阶段日程、当届 PR 上限、新费用、缺失的历史数字、实际住家距离类别、新校址距离及登录后的承诺声明措辞。

## 常见问题

### PR 孩子可以把国际学生阶段当后备吗？

不可以。应走补充轮次。若仍未成功，MOE 会分配到有空缺的学校，不保证符合偏好或距离近。

### 租得更近，就能和公民申请者站在同一起点吗？

不能，公民身份优先。在指定双轨学校内，同一轨道中搬得更近，也不会提高内部优先级。签约前先核对实际类别。

### “没有抽签”是否意味着所有 PR 都进了？

不是。较低优先级组别可能完全没有学位，却不需抽签。上表 Dazhong 的补充轮次说明了为什么要看实际录取的公民身份组别。

### 录取后还能搬家吗？

搬到同一距离类别内，可以继续履行居住要求。未完成要求就搬到类别之外，可能被 MOE 指定转校。换房前先确认适用类别，尤其要核对新制度下的实施办法。
